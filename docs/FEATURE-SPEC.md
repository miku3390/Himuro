# Himuro 功能规格与实现对照

来源：风月官网 15 个存档页面的逆向分析（2026-10-05，见仓库外 `production/report/`）。
官方只公开「方法论级」描述，无技术规格；本文档左边是官方口径，右边是我们的实现决策。

## 一、角色卡系统

**官方口径**：最小结构五件套 —— 身份一句话 / 说话方式 / 价值观 / 禁忌边界 / 对用户的称呼习惯；外加 3–5 组「用户说/角色回」示例对话锁语感；调试顺序 = 先闲聊 → 再冲突 → 最后长线剧情，每轮只改一个变量；写完先自己聊 20 轮再公开。

**Himuro 实现**：
- `characters` 表五件套字段 + `relationship`（关系）+ `firstMessage`（开场白，fy_online 教程补充口径）+ `examplesJson`（示例对话，最多 5 组，超出淘汰最早）
- 模板角色中心：3 个内置模板（温柔陪伴/傲娇斗嘴/连载剧情各一），支持直接试聊、复制为可编辑副本
- Himuro 卡 JSON 导入导出（`{format:"himuro-card", version:1, card:{...}}`）
- 复盘回写：聊天页任意角色回复可「存为示例」，连同前一条用户消息写入角色卡

## 二、世界书

**官方口径**：条目按 人物/地点/事件（+规则）分类；每条配触发关键词 + 权重；保留变更记录可回滚；「长对话不翻车，靠结构而不是靠它应该记得」。

**Himuro 实现**：
- `wb_entries`：category（人物|地点|事件|规则）、title、content、keywordsJson、weight(1-10)、sort、enabled
- 触发引擎 `matchWorldbook()`（lib/memory.ts）：扫描最近 8 条消息，关键词命中（大小写不敏感）→ 按权重降序取前 N 条（默认 6，设置页可调）注入 system prompt
- 版本管理：每次增/改/删前整本快照进 `wb_versions`（保留 30 份），管理页一键回滚，回滚前再自动快照
- 命中预览：管理页输入模拟文本实时看会命中哪些条目（调试触发词用）
- 聊天页右侧显示「本轮世界书命中」面板，注入过程对用户透明

## 三、长会话记忆（官方无技术细节，按分析报告建议实现三层）

1. **滚动摘要**：最近 12 条消息原文进 prompt；更早的历史每累计 N 条（默认 10）用轻量档压缩成 ≤300 字摘要，存 `conversations.summaryText`。失败不阻塞对话，下轮重试。
2. **世界书关键词注入**：见上。
3. **向量检索（可选）**：配置 Embedding 模型后，每条消息截取前 400 字入库 `msg_chunks`；每轮用用户消息做余弦相似度检索 top-k（默认 4，阈值 0.35），排除 verbatim 窗口避免重复。未配置自动停用。

聊天页右侧「长会话记忆（摘要）」面板可随时查看当前摘要。

## 四、双模式

**官方口径**：日常聊天 = 短提示 + 明确情绪目标（安慰/斗嘴/并肩作战）；连载剧情 = 每章末写「下一章钩子」+ 世界书记录关键事件状态，状态可追踪。

**Himuro 实现**：
- `conversations.mode`：daily / story，会话级随时切换（默认标题跟随模式更新）
- daily：输入区情绪目标 chips（安慰/斗嘴/并肩作战/撒娇/认真谈心 + 自定义），随消息一起入库并注入 prompt
- story：`chapter` 章节号 + 「开新章」按钮；system prompt 要求章末输出【下一章钩子】；侧栏「生成下一章钩子」按钮（可复制/存入世界书）；「提炼状态→世界书」用轻量模型从最近 20 条提炼 ≤3 条条目草稿，用户勾选确认后入库（对应风月「状态回写世界书」）

## 五、模型两档

**官方口径**：轻量 = 快、适合日常与试设定；高质量 = 细节情绪好、适合定稿连载；按创作阶段切换。

**Himuro 实现**：`conversations.tier` 会话级切换；`settings` 表存轻量/高质量两组 OpenAI 兼容配置（baseUrl/apiKey/model）。`baseUrl === "mock"` 时走内置演示模型（离线假回复，开箱即测）。另有一组可选 Embedding 配置。

## 六、语音

**官方口径**：语音不替代全文，只增强关键情绪节点；基底音色 → 参数微调 → 试听 → 批量导出。

**Himuro 实现（v1）**：浏览器 Web Speech API —— 设置页选中文基底音色 + 语速/音调滑杆 + 试听；聊天页每条消息「▶ 试听」。逐句/批量导出与自部署 TTS 见 Phase 2。

## 七、导出复盘

**官方口径**：每周导出最满意的 10 轮对话 → 提炼句式 → 回写角色卡。

**Himuro 实现**：`/api/export` 导出 TXT（可读剧本格式，含情绪目标与星标）/ JSON（全量结构化）；消息星标 + 「存为示例」一键回写。

## 八、明确剔除（报告建议）

邀请体系、风月币、签到积分、SEO 站群、视频生成 —— 留存/运营类功能，与核心创作体验无关。
